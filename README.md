# 🏆 LeadGrade AI

나라장터 입찰공고·낙찰이력 데이터를 교차분석해 **신용평가 영업 잠재고객을 자동 발굴**하고, TM(전화영업)과 대면영업을 하나의 흐름으로 연결하는 영업지원 AI 도구입니다.

🔗 **Live**: https://leadgrade.vercel.app

---

## 핵심 기능

- **잠재고객 발굴** — 현재 진행중인 입찰공고와 과거 낙찰이력을 교차매칭해 영업우선점수(A/B/C 등급) 산정
- **낙찰이력 DB** — 최근 5년치 낙찰데이터를 사전 구축해두고, 검색 시 즉시 조회 (실시간 API 호출 없음)
- **대시보드 / 오늘의 영업** — 저장된 기업 현황 요약, 점수순 TOP 추천 기업
- **☎️ TM 모드** — 통화결과 9종 표준코드로 기록·학습, 재접촉 대상 자동 관리
- **🏢 대면영업 모드** — 담당자 적합도(업종·지역·네트워크·업무량) 기반 배정 추천
- **TM ↔ 대면영업 자동 연계** — 통화결과가 관심고객/대면전환이면 자동으로 대면영업 대기열에 이관
- **영업 파이프라인** — 칸반보드 형태로 상태 관리 (연락전 → 계약성공)

## 기술 스택

- Frontend: Vanilla JS (단일 HTML 파일)
- Backend: Firebase Firestore
- API 프록시: Vercel Serverless Function (`api/nara.js`) — 나라장터 공공데이터 API 호출
- Hosting: Vercel

## 데이터 출처

- 조달청 나라장터 OpenAPI — 입찰공고정보서비스, 낙찰정보서비스
